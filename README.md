# Pixel Quest

Пиксельная 2D survival-sandbox RPG для Android. Чистые Kotlin + Canvas, без движков и внешних ассетов — вся графика рисуется кодом в виртуальном разрешении 320×180 и масштабируется без сглаживания (чёткие пиксели).

## Геймплей (v0.4)
- **Бесконечный мир с чанковой генерацией**: чанки 32×32 тайлов создаются на лету, пока ты идёшь; каждый мир уникален (сид запуска).
- **6 биомов**: лес, пустыня, снежные поля, вулканические земли (с лавовыми озёрами), горы, озёра — биомы определяются шумом, вулканические зоны редкие.
- **Деревни**: в лесах генерируются деревни с домами (стены, окна, деревянный пол) и жителями — тапни по жителю, чтобы поговорить.
- **Разбойники**: могут напасть в любой момент — спавнятся рядом с игроком, быстрее и злее слаймов (6 HP), дропают золото и иногда железо.
- **Руины** с золотом генерируются по всему миру.
- **Инвентарь на 40 слотов** (открывается кнопкой-сумкой справа сверху или клавишей E): верхний ряд — хотбар, стеки до **100 предметов** в слоте, перенос и объединение стеков тапами.
- **Крафт**: вкладка CRAFT в инвентаре — верстак, деревянные и каменные стены, дверь, деревянный пол, окно, забор, печь, железные меч и кирка.
- **Строительство по сетке**: выбери блок в хотбаре и тапни — ставится на клетку перед персонажем. Построенное (и стены деревенских домов) можно сломать топором или киркой, блоки выпадают обратно.
- **Верстак**: крафт сложных предметов работает только рядом с поставленным верстаком (радиус 2 клетки).
- **Здоровье 10 сердец**, отбрасывание, неуязвимость после урона, смерть и респаун.
- **Предмет в руке**: выбранный инструмент отображается в руке персонажа и анимируется при использовании; железные меч и кирка сильнее обычных (урон ×2, добыча ×2).
- **Добыча ресурсов**: деревья и кактусы рубятся топором, камень и руда добываются киркой; у каждого ресурса своя прочность.
- **Враги по биомам**: зелёные, песчаные, ледяные, магмовые и каменные слаймы — разные цвета, HP и скорость; спавнятся динамически вокруг игрока.
- Название биома и события показываются всплывающими сообщениями.

## Управление
- **Левая половина экрана** — виртуальный джойстик (тяни в нужную сторону).
- **Кнопка USE справа снизу** (или тап по правой половине экрана) — использовать предмет (атака/добыча/установка блока) / старт / респаун.
- **Джойстик** отображается визуально (база + ручка) там, где ты коснулся левой половины экрана.
- **Кнопка-сумка справа сверху** (или клавиша **E**) — открыть/закрыть инвентарь (40 слотов + крафт).
- **Хотбар внизу экрана** — тап по слоту, чтобы сменить предмет в руке.
- В инвентаре: тап по предмету — выбрать, тап по другому — переместить/объединить стеки; вкладка CRAFT — тап по рецепту.
- В эмуляторе: WASD/стрелки + Space, E — инвентарь.

## Совместимость
Приложение не содержит нативного кода, поэтому APK работает на всех архитектурах, включая **32-битные (armeabi-v7a)** и 64-битные устройства. minSdk 21 (Android 5.0+), targetSdk 34.

## Сборка APK
APK собирается автоматически через GitHub Actions при каждом пуше в `main`:

1. Открой вкладку **Actions** → последний успешный запуск **Android CI**.
2. Скачай артефакт **PixelQuest-debug-apk**.
3. Установи `app-debug.apk` на телефон (разреши установку из неизвестных источников).

Локально:
```bash
./gradlew assembleDebug   # или: gradle assembleDebug
```

## Технические детали
- Kotlin, без зависимостей и без нативного кода (32/64-бит из коробки).
- Игровой цикл на отдельном потоке через `SurfaceView`.
- Виртуальный экран 320×180, тайлы 16×16, чанки 32×32 (бесконечный мир).
- Биомы на value-noise (высота + температура + вулканический шум), деревни и руины — детерминированно по регионам 64×64.
- Коллизии AABB по тайлам, камера следует за игроком.

## Структура
```
app/src/main/java/com/gkim/pixelquest/
├── MainActivity.kt   — активити, полноэкранный режим
├── GameView.kt       — SurfaceView, игровой цикл, ввод (джойстик, тапы, хотбар)
└── Game.kt           — мир, биомы, сущности, инвентарь, логика, рендер, HUD
```
