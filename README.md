# Pixel Quest

Пиксельная 2D top-down приключенческая игра для Android. Чистые Kotlin + Canvas, без движков и внешних ассетов — вся графика рисуется кодом в виртуальном разрешении 320×180 и масштабируется без сглаживания (чёткие пиксели).

## Геймплей
- Исследуй процедурно сгенерированный мир: лес, пруд, тропинки.
- Собери **10 кристаллов**, чтобы победить.
- Убивай слаймов мечом (2 удара), они преследуют тебя и наносят урон.
- 3 сердца здоровья, отбрасывание при ударе, неуязвимость после урона.

## Управление
- **Левая половина экрана** — виртуальный джойстик (тяни в нужную сторону).
- **Правая половина экрана** — удар мечом / старт / рестарт.
- В эмуляторе: WASD/стрелки + Space.

## Сборка APK
APK собирается автоматически через GitHub Actions при каждом пуше в `main`:

1. Открой вкладку **Actions** → последний запуск **Android CI**.
2. Скачай артефакт **PixelQuest-debug-apk**.
3. Установи `app-debug.apk` на телефон (разреши установку из неизвестных источников).

Локально:
```bash
./gradlew assembleDebug   # или: gradle assembleDebug
```

## Технические детали
- Kotlin, minSdk 21, targetSdk 34, без зависимостей.
- Игровой цикл на отдельном потоке через `SurfaceView`.
- Виртуальный экран 320×180, тайлы 16×16, карта 64×64.
- Коллизии AABB по тайлам, камера следует за игроком.

## Структура
```
app/src/main/java/com/gkim/pixelquest/
├── MainActivity.kt   — активити, полноэкранный режим
├── GameView.kt       — SurfaceView, игровой цикл, ввод (джойстик/атака)
└── Game.kt           — мир, сущности, логика, рендер, HUD
```
